**English**

- **Summaries with your ChatGPT account.** If you have ChatGPT Plus or Pro, connect it in Settings → Accounts & API keys to generate summaries without an OpenAI API key. Usage counts toward your plan limits. Transcribing with OpenAI still requires an API key.
- **Easier model selection.** The model fields are now a dropdown that always lists every available model. Use the refresh button next to it to load the latest list.

**Español**

- **Resúmenes con tu cuenta de ChatGPT.** Si tienes ChatGPT Plus o Pro, conéctala en Ajustes → Cuentas y API keys para generar resúmenes sin API key de OpenAI. El uso cuenta contra los límites de tu plan. Para transcribir con OpenAI sigue haciendo falta una API key.
- **Elegir el modelo es más fácil.** Los campos de modelo ahora son un desplegable que muestra siempre todos los modelos disponibles. Pulsa el botón de recargar que está al lado para cargar la lista actualizada.
